## Cloud Functions

- Runtime: Python 3.12, 2nd Gen
- Region: `europe-west1` for all functions
- Memory: 256–1024 MB depending on function (catalog = 1 GB for build processing)

## Firestore

- Region: `europe-west1`
- All collections locked to Cloud Functions via Admin SDK — no client direct writes
- Composite indexes in `firestore.indexes.json`

## Firebase Storage

- Game builds: `games/{gameId}/builds/`
- Game assets: `games/{gameId}/assets/`
- LiveOps JSON: `liveops/{gameId}/liveops.json`, `liveops/{gameId}/discountoffers.json`
- Cache-Control on LiveOps files: `public, max-age=900`

## Cloudflare

- Workers serve game assets from `games.susaplay.com`
- R2 bucket for game build CDN (zero egress cost)
- Workers KV for per-game config caching

## CI/CD

Bitbucket Pipelines — selective deploy on merge:

- Merge to `develop` → deploy to staging (`susaplaytest`)
- Merge to `main` → deploy to production (`susaplay-2e8e3`)

Only changed components deploy (functions, hosting targets, rules/indexes checked independently).
