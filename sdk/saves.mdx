## Read

```javascript
const save = await SusaPlay.saves.read({ slotId: 'main' })
// Returns null if no save exists yet
if (save) {
  loadProgress(save.data)
  localVersion = save.version
}
```

## Write

```javascript
await SusaPlay.saves.write({
  slotId: 'main',
  data: { level: 5, coins: 1200 },
  version: localVersion, // pass 0 for first write
})
```

The server increments `version` on every successful write. Store the returned version locally.

## Conflict resolution

If another session wrote while you were playing, `VERSION_CONFLICT` is thrown:

```javascript
async function saveWithRetry(slotId, newData) {
  try {
    await SusaPlay.saves.write({ slotId, data: newData, version: localVersion })
  } catch (err) {
    if (err.code === 'VERSION_CONFLICT') {
      const server = await SusaPlay.saves.read({ slotId })
      const merged = mergeData(newData, server.data)
      await SusaPlay.saves.write({ slotId, data: merged, version: server.version })
      localVersion = server.version + 1
    }
  }
}
```

## Multiple slots

Use slots to isolate concerns:

```javascript
// Separate slots — no cross-slot version conflict
await SusaPlay.saves.write({ slotId: 'progress', data: progressData, version: pv })
await SusaPlay.saves.write({ slotId: 'settings', data: settingsData, version: sv })
```

## Limits

- Max 1 MB per slot
- Slot ID: alphanumeric \+ underscores, max 64 chars
- No limit on number of slots per player

## Error codes

| Code | Cause |
| --- | --- |
| `VERSION_CONFLICT` | Another session wrote first — re-read and retry |
| `INVALID_ARGUMENT` | Data exceeds 1 MB or malformed slot ID |
| `UNAUTHENTICATED` | Player session expired |
