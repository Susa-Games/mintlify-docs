## Prerequisites

- A SusaPlay developer account ([register at dev.susaplay.com](https://dev.susaplay.com))
- A Unity game you can build for WebGL — SusaPlay runs WebGL games only

## Step 1 — Register your game

1. Open [Developer Portal → Register Game](https://dev.susaplay.com/games/new)
2. Fill in name, description and thumbnail
3. Copy the game key. It is always on the game's **Overview** tab, and it is public by design:
   it ships in every build and only identifies the game

A Public game starts private — only you can play it until SusaPlay approves its
[public request](/integration/release-review#private-games).

```text
gk_xxxxxxxxxxxxxxxxxxxxxxxx
```

## Step 2 — Install the SDK

Add the package to your Unity project's `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.susaplay.sdk": "https://github.com/Susa-Games/com.susaplay.sdk.git#v1.9.1"
  }
}
```

Then open **SusaPlay → Setup** from the Unity menu, paste your game key, and click **Save**. This
creates `Assets/Resources/PlatformConfig.asset`.

## Step 3 — Initialize

```csharp
using susaplay.SDK;
using UnityEngine;

public class Bootstrap : MonoBehaviour
{
    private async void Start()
    {
        await SusaPlaySDK.Initialize();
        Debug.Log($"Player: {SusaPlaySDK.Auth.DisplayName}");
        SusaPlaySDK.MarkGameLoaded();
    }
}
```

## Step 4 — Verify it works

```csharp
var wallet = await SusaPlaySDK.Purchases.GetPlatformWallet();
Debug.Log($"Wallet: {wallet.Success}");
```

Build for WebGL and upload it on the game's **Builds** tab. When processing finishes, click
**Preview** on the build's row. If the console shows the player name and a wallet response, you
are connected.
