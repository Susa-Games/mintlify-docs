## Overview

Every game on SusaPlay has a game entry that holds metadata, build history, economy config, and credentials. You register once — then all SDK and API calls reference that game.

## Steps

### 1. Open the Developer Portal

Go to [dev.susaplay.com](https://dev.susaplay.com) → **Register Game**.

### 2. Fill in game metadata

| Field | Notes |
| --- | --- |
| Name | Public-facing title shown in the developer catalog |
| Description | Required. Summary for reviewers — mention gameplay loop and target audience. A public game needs at least 200 characters before it can go public |
| Thumbnail (landscape cover) | Required. Choose a JPEG, PNG, or WebP image, then crop it to 16:9 — shown on the game's card. Replace it later from the Overview tab |
| Genre | Used for internal filtering — pick the closest fit |
| Distribution | `Public` or `B2B` — determines who can access the game shell |

A game registered for the **Public** catalog starts **private**: only you can play it, from the
Developer Portal. See [Private games](/integration/release-review#private-games). A **B2B** game
does not start private.

### 3. Copy the game key

After registration, a game key is generated:

```text
gk_xxxxxxxxxxxxxxxxxxxxxxxx
```

The game key is always shown on the game's **Overview** tab. It is public by design: it ships in
every build and only identifies the game, so it cannot be regenerated. It is not a secret — the
secret credential is your [developer API key](/integration/api-keys).

SusaPlay runs WebGL games only, so there is no platform to choose.

You can tick **Upload the first build now** to go straight to the Builds tab, or upload it later.

### 4. Add covers and screenshots

The game's **Overview** tab has a **Covers** section with three slots. Each image is cropped in
the portal to its slot's shape when you choose it, so the site never cuts part of it off.

| Image | Ratio | Minimum | Exported at (up to) | Required |
| --- | --- | --- | --- | --- |
| Landscape cover | 16:9 | 1280×720 | 1920×1080 | Yes |
| Square cover | 1:1 | 512×512 | 800×800 | No — the landscape cover is used where it is missing |
| Portrait cover | 2:3 | 600×900 | 800×1200 | No — stored for upcoming layouts |
| Screenshots (up to 3) | 16:9 | 1280×720 | 1920×1080 | No |

Keep the three covers consistent — same art, same title — and put no other text on them.

Add up to 3 screenshots showing real gameplay. They are not required to request going public,
but reviewers look for them. Source images must be JPEG, PNG, or WebP; SVG is rejected. To add a
fourth screenshot you have to delete an existing one first.
