SusaPlay handles the backend infrastructure for Unity WebGL games — so you can focus on the game itself.

## What SusaPlay provides

| Service | What it does |
| --- | --- |
| **Identity** | Player auth, guest sessions, account management |
| **Economy** | Wallet, virtual currencies, store items, real-money checkout |
| **LiveOps** | Campaign delivery without app updates |
| **Catalog** | Build uploads, versioning, release review |
| **Webhooks** | Real-time platform events to your backend |
| **Saves** | Versioned cloud saves across devices |
| **Analytics** | Session tracking, custom events, active players and retention |

## Platform basics

- **SDK:** Unity (UPM package), for WebGL builds only
- **Testing before release:** a new game stays private until it is approved, and its builds can be played from the Developer Portal with **Preview** and **Share**
- **Developer access:** [dev.susaplay.com](https://dev.susaplay.com)
